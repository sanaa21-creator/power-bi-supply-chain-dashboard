# power-bi-supply-chain-dashboard
Supply Chain Analysis and KPI Dashboard using Power BI

Power BI Supply Chain Dashboard

Project Overview : 
- This project analyzes supply chain performance using Power BI. It aims to monitor key performance indicators (KPIs) and identify opportunities to improve operational efficiency.

Objectives:
- Analyze supply chain and order data.
- Monitor key performance indicators.
- Identify trends in revenue, costs, and delivery performance.
- Support data-driven decision-making.

Tools Used:
- Microsoft Power BI
- Power Query for data cleaning and transformation
- DAX for KPI calculations
- Project Workflow

Data cleaning and preparation :
- KPI calculation using DAX
- Dashboard design and visualization
- Analysis of supply chain performance

Key KPIs:
- Total Revenue
- Total Costs
- Total Profit
- Order Volume
- Delivery Performance
